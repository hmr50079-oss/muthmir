# مثمر

مساحة شخصية عربية بالكامل (RTL) لتنظيم المهام اليومية، ترتيب الأولويات، ومتابعة الإنجاز — بواجهة هادئة مستوحاة من هوية الأعمال الاحترافية، وبيانات محفوظة داخل متصفح المستخدم.

## التشغيل

لا يحتاج المشروع إلى بناء أو تثبيت حزم:

1. افتح `index.html` مباشرة في المتصفح، أو
2. شغّل خادمًا محليًا بسيطًا من مجلد المشروع ثم افتح:
   `http://localhost:4173/`

> يفضّل استخدام خادم محلي حتى تعمل روابط الخطوط والتنزيلات بشكل متسق. يعمل الموقع أيضًا عند فتح الملف مباشرة في المتصفحات الحديثة.

## الحساب التجريبي

- البريد: `demo@muthmir.app`
- كلمة المرور: `Muthmir2026!`
- أو اضغط زر **استكشف مساحة عمل تجريبية** من شاشة الدخول.

كل حساب جديد يبدأ بمساحة فارغة ومستقلة تمامًا عن بقية الحسابات.

## المزايا

- **حسابات محلية متعددة** مع تسجيل دخول وخروج وجلسة اختيارية «تذكّرني».
- **عزل كامل للبيانات**: لكل مستخدم مفتاح تخزين خاص، ولا تظهر مهامه لحساب آخر.
- **كلمات مرور محمية** عبر PBKDF2 مع ملح فريد لكل حساب (وتجزئة احتياطية عند عدم توفر Web Crypto).
- **لوحة اليوم**: المهام المتأخرة، المستحقة اليوم، بدون موعد، والمكتملة اليوم.
- **إدارة كاملة للمهام**: إضافة، تعديل، إنجاز، تراجع، حذف، ملاحظات، أولوية، تصنيف، تاريخ ووقت.
- **تذكيرات** داخل الصفحة وإشعارات متصفح اختيارية أثناء بقاء الموقع مفتوحًا.
- **عروض متعددة**: جميع المهام، المهام القادمة، والمكتملة.
- **بحث فوري** وتصفية حسب الأولوية والتصنيف وترتيب حسب الأهمية أو الموعد أو الأحدث.
- **إعدادات الحساب**: تحديث الاسم والبريد، تغيير كلمة المرور، حالة الإشعارات.
- **نسخ احتياطي JSON** واستيراد مع استبدال آمن بعد تأكيد.
- **مسح المهام المكتملة** وحذف الحساب نهائيًا من منطقة الخطر.
- واجهة متجاوبة بالكامل مع الهاتف واللوحي وسطح المكتب.

## البيانات والخصوصية

- تُحفظ الحسابات في `muthmir:users:v1`.
- تُحفظ جلسة الدخول في `localStorage` أو `sessionStorage` حسب خيار «تذكّرني».
- تُحفظ مهام كل مستخدم في مفتاح مستقل:
  `muthmir:data:v1:<userId>`
- لا تُرسل البيانات إلى أي خادم؛ التطبيق يعمل بالكامل داخل المتصفح.
- كلمة المرور لا تُخزّن كنص واضح، بل كتجزئة PBKDF2 مع ملح.
- **ملاحظة**: مهام المستخدم محفوظة في `localStorage` بصيغة JSON غير مشفّرة. استخدم جهازًا موثوقًا، وصدّر نسخة احتياطية قبل مسح بيانات الموقع.
- حذف بيانات الموقع من المتصفح يحذف الحسابات والمهام نهائيًا.

## التوافق

يعمل مع الإصدارات الحديثة من Chrome وEdge وFirefox وSafari. يلزم تفعيل JavaScript. بعض مزايا الإشعارات تحتاج إذنًا من المتصفح وقد لا تعمل في وضع التصفح الخاص.
