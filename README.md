# مثمر

مساحة شخصية عربية بالكامل (RTL) لتنظيم المهام اليومية، ترتيب الأولويات، ومتابعة الإنجاز — بواجهة هادئة مستوحاة من هوية الأعمال الاحترافية، مع حساب مستقل لكل مستخدم وبيانات محفوظة بأمان في **Supabase**.

## التشغيل

لا يحتاج المشروع إلى بناء أو تثبيت حزم:

1. أضف إعدادات Supabase كما في القسم التالي.
2. افتح `index.html` مباشرة في المتصفح، أو
3. شغّل خادمًا محليًا بسيطًا من مجلد المشروع ثم افتح:
   `http://localhost:4173/`

> يفضّل استخدام خادم محلي حتى تعمل روابط الخطوط والتنزيلات بشكل متسق. يعمل الموقع أيضًا عند فتح الملف مباشرة في المتصفحات الحديثة.

## إعداد Supabase

### 1) إنشاء الجدول وسياسات الحماية

افتح مشروعك في [Supabase](https://supabase.com)، ثم:

1. اذهب إلى **SQL Editor**.
2. انسخ محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) كاملًا.
3. الصقه وشغّله مرة واحدة.

ينشئ الملف:

- جدول `public.tasks` مع القيود والفهارس.
- تحديث `updated_at` تلقائيًا.
- تفعيل **Row Level Security (RLS)** وأربع سياسات تمنع أي مستخدم من قراءة أو تعديل مهام غيره.
- دالة `replace_my_tasks` لاستيراد النسخة الاحتياطية داخل معاملة واحدة.
- دالة `delete_my_account` لحذف صاحب الجلسة فقط (راجع ملاحظة الأمان أدناه).

> **ترقية جدول قديم:** إذا كان جدول `public.tasks` موجودًا مسبقًا بنسخة مبسّطة، فالملف يضيف الأعمدة الناقصة ويحوّل `is_completed` إلى `completed` دون حذف الصفوف. راجع نتائج استعلامات التحقق في نهاية الملف بعد التشغيل. إذا أردت بداية نظيفة تمامًا، احذف الجدول القديم أولًا (سيؤدي ذلك إلى حذف بياناته).

### 2) إعدادات الاتصال

1. انسخ `supabase-config.example.js` إلى `supabase-config.js`.
2. من لوحة Supabase، اذهب إلى **Project Settings → API**.
3. ضع `Project URL` في `url`.
4. ضع **anon / publishable key** في `anonKey`.

```js
window.MUTHMIR_SUPABASE = {
  url: "https://YOUR-PROJECT-REF.supabase.co",
  anonKey: "YOUR-ANON-OR-PUBLISHABLE-KEY"
};
```

> `supabase-config.js` مستثنى من Git عبر `.gitignore`. لا تضع مفتاح `service_role` في هذا الملف أو في أي ملف يصل إلى المتصفح.

### 3) إعدادات المصادقة

من **Authentication → Providers → Email**:

- أبقِ مزوّد البريد مفعّلًا.
- يمكنك إبقاء **Confirm email** مفعّلًا (موصى به للإنتاج). بعد التسجيل سيصل رابط تأكيد إلى بريد المستخدم.
- أضف رابط موقعك (و`http://localhost:4174` أثناء التطوير) إلى **Authentication → URL Configuration → Redirect URLs** ليعمل رابط تأكيد البريد.
- لتجربة زر **استكشف مساحة عمل تجريبية**، فعّل **Anonymous sign-ins** من إعدادات المصادقة. كل زائر يحصل على جلسة مجهولة مستقلة، فلا يرى بيانات غيره.

## الحساب التجريبي

لا يوجد حساب تجريبي مشترك بكلمة مرور. زر **استكشف مساحة عمل تجريبية** ينشئ جلسة مجهولة جديدة ويعبّئها بمهام تجريبية. هذه المساحة مؤقتة ولا ترتبط ببريد، ويمكن حذفها من منطقة الخطر.

لإنشاء حساب دائم، استخدم نموذج **أنشئ حسابك المجاني** ثم أكّد البريد إن كان خيار التأكيد مفعّلًا.

## المزايا

- **مصادقة سحابية عبر Supabase Auth** مع تسجيل دخول وخروج وجلسة محفوظة.
- **عزل كامل للبيانات** عبر RLS: كل مستخدم يرى صفوفه فقط.
- **إدارة كاملة للمهام**: إضافة، تعديل، إنجاز، تراجع، حذف، ملاحظات، أولوية، تصنيف، تاريخ ووقت.
- **لوحة اليوم**: المهام المتأخرة، المستحقة اليوم، بدون موعد، والمكتملة اليوم.
- **تذكيرات** داخل الصفحة وإشعارات متصفح اختيارية أثناء بقاء الموقع مفتوحًا.
- **عروض متعددة**: جميع المهام، المهام القادمة، والمكتملة.
- **بحث فوري** وتصفية حسب الأولوية والتصنيف وترتيب حسب الأهمية أو الموعد أو الأحدث.
- **إعدادات الحساب**: تحديث الاسم، تغيير البريد (مع تأكيد)، تغيير كلمة المرور، حالة الإشعارات.
- **نسخ احتياطي JSON** واستيراد مع استبدال آمن بعد تأكيد.
- **مسح المهام المكتملة** وحذف الحساب نهائيًا من منطقة الخطر.
- واجهة متجاوبة بالكامل مع الهاتف واللوحي وسطح المكتب.

## البيانات والخصوصية

- تُحفظ المهام في جدول `public.tasks` داخل Supabase.
- كل صف مرتبط بـ `auth.users.id`، وسياسات RLS تمنع الوصول بين المستخدمين.
- جلسة الدخول يديرها Supabase Auth في تخزين المتصفح الآمن الخاص بالمكتبة.
- لا توجد مهام أو كلمات مرور مخزّنة في `localStorage` يدويًا.
- كلمة المرور يديرها Supabase Auth ولا تُخزّن كنص واضح في التطبيق.
- **مفتاح anon عام بطبيعته** ويُستخدم في المتصفح؛ الحماية الحقيقية تأتي من RLS. أما `service_role` فهو سري ولا يوضع في الواجهة.
- **حذف الحساب** يستخدم دالة `delete_my_account` ذات `security definer`، وهي تحذف صاحب الجلسة فقط. راجعها مع مسؤول قاعدة البيانات، أو استبدلها بـ Edge Function تستخدم `service_role` على الخادم.
- **النسخ الاحتياطي** ملف JSON يُنزّل إلى جهازك؛ احتفظ به في مكان آمن.

## التوافق

يعمل مع الإصدارات الحديثة من Chrome وEdge وFirefox وSafari. يلزم تفعيل JavaScript واتصال بالإنترنت للوصول إلى Supabase. بعض مزايا الإشعارات تحتاج إذنًا من المتصفح وقد لا تعمل في وضع التصفح الخاص.
